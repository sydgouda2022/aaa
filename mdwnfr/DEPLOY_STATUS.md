# MdwNfr iPhone PWA deployment status

Source: MdwNfr v0.1.42 Python-first implementation.
Self-hosted Pyodide v0.27.8 / Python 3.12 and Noto Sans Egyptian Hieroglyphs OFL font are populated by GitHub Actions.
Artwork has been optimized for mobile delivery with SHA-256 catalog updates, retaining the existing silhouette profiles.
Full TLA/AED/AES/ORAEC lexicon is NOT included; the development dataset is 665 entries and 728 spellings.
PDF/DOCX/native .mdwnfr portability remains incomplete. This is a functional development preview, not a completed product.
Documents are stored in local browser IndexedDB; always keep backups of important work.
